# HomeDeck — 우리집 3D 인테리어 시뮬레이터

인테리어 업체가 준 SketchUp 렌더(탑뷰 평면도 + 실내 12컷)를 바탕으로 집 전체를 Three.js 로 다시 세운 페이지.
브라우저에서 **색·마감을 칠하고 가구를 끌어서 배치**할 수 있다. 설치·빌드 없음 — 정적 파일 그대로 동작.

- 실행(로컬): 이 폴더에서 `python -m http.server 8123` → <http://127.0.0.1:8123/>
  (`file://` 로는 ES 모듈이 막히므로 정적 서버가 필요. Three.js 는 CDN 이라 인터넷은 필요)
- 저장소는 private 로 유지 — GitHub Pages 는 공개 전환 후 `.github/workflows/pages.yml` 을 수동 실행하면 켜진다

## 할 수 있는 것

| 기능 | 방법 |
|---|---|
| 디자인 스킴 | **✨ 디자인** 탭 — 원안 + 13종(노르딕 라이트 · 재팬디 웜그레이 · 웨스트코스트 오가닉 · 파리지앵 클래식 화이트 · 테라코타 어스 · 세이지 그린 코티지 · 딥 네이비 & 브라스 · 차콜 인더스트리얼 · 크림 & 카라멜 미드센추리 · 그레이 모노톤 · 스톤 & 린넨 · 블랙 & 오크 · 더스티 로즈 & 그레이지). 벽·천장·방별 바닥·주방·가구·욕실·텍스타일 색과 마감 + 색온도만 바뀌고 **가구 배치는 그대로**. 보고 있던 시점 유지 |
| 시점 이동 | 상단 **시점** 메뉴에 원본 렌더 12컷과 같은 구도 + 탑뷰(지붕 투시) |
| 걷기 | **🚶 걷기** → 마우스 둘러보기 · W A S D · Shift 달리기 · Esc |
| 색·마감 | 벽·바닥·천장·가구 면을 **클릭** → 색상 선택기 + 마감(벽지·타일·원목·대리석·콘크리트·유광…) |
| 가구 배치 | **가구** 탭에서 추가 → 드래그 이동 · Q/E 15° · R 90° · Delete |
| 욕실 | **가구** 탭 하단 — 벽걸이 사각 세면대·거울장·양변기·수건걸이(수건)·휴지걸이·젠다이·타일 파티션·휴지통. 벽부착품은 `y0`(설치 높이)로 조절 |
| 조명 | 3인치 LED 매입등·LED 평판·식탁등(돔/라인)·유리 구 펜던트·링 디자인등·간접조명·레일 스팟을 가구처럼 추가/이동/삭제. 밝기는 **소비전력(W)** 기준으로 계산(LED 100 lm/W → 광도, 매입등 5 W · 평판등 40 W 기본, 아이템별로 W 입력 가능). 개별 켜짐·세기 배율·색온도(2700–6500K), 상단 **조명** 슬라이더로 전체 세기, **색온도** 셀렉트로 전체 색온도 |
| 마그네틱 레일 | 서울L&D몰 "마그네틱 조명 LED 라인 레일" 기준 — **레일**(매입형 기본, `exposed`로 노출형) + **라인등 300/600/900**·**라인렌즈 300/600/900**·**원형 스포트 10W**(`tilt` 각도)·**사각 듀얼 스포트 20W**. 등기구는 레일 선상에 각각 놓는다. 색온도 3000/4000/5700K |
| 기본 가구 수정 | 잠겨 있음. 선택 후 **잠금** 해제하면 이동·치수 변경 가능 |
| 저장 | 브라우저에 자동 저장(localStorage) · **내보내기/불러오기** 로 JSON 이동 · 📷 PNG |
| 원본 | **↺ 원본** — `plan.js`의 `DEFAULT_ITEMS`(배치)와 `materials.js`의 `DEFAULT_PAINTS`(색)가 원본 구조. 수정 후 언제든 이 버튼으로 복귀. 원본을 바꾸려면 배치를 내보내 `plan.js`에 반영하고 `PLAN_VERSION`을 올린다 |

## 구조

```
index.html          UI 골격 + importmap(three@0.170 CDN)
css/style.css
js/plan.js          평면 데이터 — 벽·방·문·창·조명·카메라 프리셋·기본 가구 (설계도 실측 mm)
js/textures.js      캔버스 절차 텍스처(타일·원목·벽지·콘크리트·대리석·패브릭)
js/materials.js     페인트 레지스트리 — 칠할 수 있는 면 키 하나당 재질 하나
js/builders.js      벽/바닥/문/창 빌더 + 가구 빌더(BUILDERS) + 조명 빌더(LIGHT_BUILDERS, 광원 포함) + 카탈로그
js/schemes.js       디자인 스킴 4종 — 색·마감 패치 + 거실 아이템 + 색온도
js/app.js           씬·카메라·선택/드래그·패널·저장·스킴 적용
```

## 치수

`plan.js` 좌표는 **설계 평면도 실측(mm)** 이다(`S = 0.001`). 설계도는 현관이 위(복도 쪽)지만 인테리어 렌더는
그 도면을 180° 돌린 방향이라 모델은 렌더 방향(현관 남쪽)을 따른다.

- 세대 외곽 11,700 × 9,000 · 격자 x: 1,300 | 5,200 | 6,800 | 6,900 | 7,600 | 10,300 · z: 1,600 | 3,300 | 6,000 | 7,000 · 서쪽 열은 4,500 에서 다용도실/거실 분할
- 안방 3,900×4,500 · 거실 5,200×4,500(서쪽 발코니 확장, +복도) · 안방욕실 1,600×1,600 · 공용욕실 2,400×1,700 · 작은방 ㄱ자(4,900×1,600 + 4,100×1,700, 동쪽 발코니 확장) · 주방 4,100×2,700 · 서재 3,400×3,000 · 현관 사선 중문 + 북벽 7,000 · 다용도실 1,300 (거실 쪽 문) · 서재 발코니 1,400
- 벽·문·창 위치는 도면 + 탑뷰 렌더로 보정. 가구·붙박이 치수는 렌더에서 읽은 추정치

## 평면 해석(원본 렌더 → 모델)

- 좌측 세로 발코니(다용도실, 세탁타워) — 안방 서쪽 창으로 연결
- 안방: 북벽 붙박이장 7도어 + NE 화장대, 퀸침대 남북 방향, 동벽에 안방욕실 문·방문
- 욕실 2개(안방욕실·공용욕실) 중앙 상단, 타일 벽·거울장·벽걸이 세면대
- 거실: 안방 남벽에 TV 붙박이장(양끝 선반 컬럼), 남벽 소파, 서쪽 발코니 창
- 현관: 남쪽 현관문 → 사선 중문(흑 프레임 유리) → 거실, 동쪽 신발장(간접등 니치)
- 주방: 복도 끝 오븐 키큰장(NEFF 2단) → 남벽 상부장·후드+쿡탑 → 남벽 동쪽 끝 서재 발코니 문 → 동벽 싱크(위에 작은 창, 창 위까지 상부장)·우측 식기세척기 → 북벽 냉장고
- 서재(현관 오른쪽 방): 들어서서 오른쪽(서벽) 천장까지 장 → 그 중간에서 ㄱ자 책상 → 맞은편 하부장. 동벽 남쪽 천장까지 옷장, 옷장 앞·책상 뒤(창 아래) 낮은 침대 선반 + 미닫이 수납. 천장 패널등·시스템에어컨
- 작은방: 북동, 발코니 창
