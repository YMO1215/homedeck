# HomeDeck — 우리집 3D 인테리어 시뮬레이터

인테리어 업체가 준 SketchUp 렌더(탑뷰 평면도 + 실내 12컷)를 바탕으로 집 전체를 Three.js 로 다시 세운 페이지.
브라우저에서 **색·마감을 칠하고 가구를 끌어서 배치**할 수 있다. 설치·빌드 없음 — 정적 파일 그대로 동작.

- 실행: <https://ymo1215.github.io/homedeck/> (GitHub Pages) — 또는 `index.html` 을 아무 정적 서버로 열기
- 로컬: `python -m http.server 8123` 후 `http://127.0.0.1:8123/`
  (`file://` 로는 ES 모듈이 막히므로 서버가 필요)

## 할 수 있는 것

| 기능 | 방법 |
|---|---|
| 시점 이동 | 상단 **시점** 메뉴에 원본 렌더 12컷과 같은 구도 + 탑뷰(지붕 투시) |
| 걷기 | **🚶 걷기** → 마우스 둘러보기 · W A S D · Shift 달리기 · Esc |
| 색·마감 | 벽·바닥·천장·가구 면을 **클릭** → 색상 선택기 + 마감(벽지·타일·원목·대리석·콘크리트·유광…) |
| 가구 배치 | **가구** 탭에서 추가 → 드래그 이동 · Q/E 15° · R 90° · Delete |
| 기본 가구 수정 | 잠겨 있음. 선택 후 **잠금** 해제하면 이동·치수 변경 가능 |
| 저장 | 브라우저에 자동 저장(localStorage) · **내보내기/불러오기** 로 JSON 이동 · 📷 PNG |

## 구조

```
index.html          UI 골격 + importmap(three@0.170 CDN)
css/style.css
js/plan.js          평면 데이터 — 벽·방·문·창·조명·카메라 프리셋·기본 가구 (탑뷰 px 좌표)
js/textures.js      캔버스 절차 텍스처(타일·원목·벽지·콘크리트·대리석·패브릭)
js/materials.js     페인트 레지스트리 — 칠할 수 있는 면 키 하나당 재질 하나
js/builders.js      벽/바닥/문/창/조명 빌더 + 가구 빌더(BUILDERS) + 카탈로그
js/app.js           씬·카메라·선택/드래그·패널·저장
```

## 치수 보정

좌표는 탑뷰 이미지 픽셀이고 `plan.js` 의 `S = 0.014`(1px = 14mm) 로 m 로 바꾼다.
집 외곽 855px ≈ 12.0m × 650px ≈ 9.1m 로 잡은 추정치. 실측(전용면적·방 폭 하나)이 있으면 `S` 하나만 고치면 전체가 맞춰진다.

## 평면 해석(원본 렌더 → 모델)

- 좌측 세로 발코니(다용도실, 세탁타워) — 안방 서쪽 창으로 연결
- 안방: 북벽 붙박이장 7도어 + NE 화장대, 퀸침대 남북 방향, 동벽에 안방욕실 문·방문
- 욕실 2개(안방욕실·공용욕실) 중앙 상단, 타일 벽·거울장·벽걸이 세면대
- 거실: 안방 남벽에 TV 붙박이장(양끝 선반 컬럼), 남벽 소파, 서쪽 발코니 창
- 현관: 남쪽 현관문 → 사선 중문(흑 프레임 유리) → 거실, 동쪽 신발장(간접등 니치)
- 주방: 복도 끝 오븐 키큰장(NEFF 2단) → 남벽 쿡탑+후드 → 동벽 싱크(창) → 북벽 냉장고
- 서재: 남·서벽 ㄴ자 하부장 + 키큰장, 동쪽 발코니 창, 천장 패널등·시스템에어컨
- 작은방: 북동, 발코니 창
